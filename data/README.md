# Data Directory

This directory contains research data and sample inputs for the Bodies of Flora pipeline.

## Contents

### `plant_texts/`

Sample plant descriptions that can be used as input to the pipeline:
- Scientific names (e.g., "Helonias bullata")
- Common names (e.g., "Swamp Pink")
- Indigenous names (e.g., "miskominagaawanzh")
- Descriptive references (e.g., "the root that bleeds red")

### `research/`

Research database files:
- `bodies_flora_research_data.xlsx` - Research database with species information
- `text_input_for_bof_model_app.xlsx` - Additional test inputs

## Indigenous Knowledge Attribution

This project includes indigenous plant names and traditional ecological knowledge,
particularly from Ojibwe (Anishinaabe) sources. These names represent generations
of botanical knowledge and should be treated with respect.

The indigenous alias map includes:
- **miskominagaawanzh** (Ojibwe) → Sarracenia purpurea (Pitcher Plant)
- Various descriptive names that encode morphological and ecological knowledge

## Data Sources

Research data was compiled from:
- USDA Plants Database
- State herbarium records
- Conservation status databases
- Published botanical literature
